# TP — Juego Arcade con Guion (Godot 4)

Trabajo práctico integrador: un **juego de arcade antiguo** (oleadas, vidas,
récord) con **capa narrativa** — diálogos serializados en JSON, decisiones con
banderas y múltiples finales — implementado con **Godot 4** y diseñado con el
proceso de 8 pasos de la clase _Creación de guiones para juegos_.

| Archivo                                  | Qué contiene                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| [TP_Juego_Arcade.md](TP_Juego_Arcade.md) | Consigna completa: objetivos, entregables E1–E4, cronograma y rúbrica          |
| [template/](template/)                   | Proyecto Godot 4 armado (escenas, scripts, guion de ejemplo y test automático) |

Arranque rápido:

```bash
cd games/arcade/template
godot --path . --editor                                    # abrir
godot --headless --path . --script res://tests/recorrer_juego.gd   # verificar
```
